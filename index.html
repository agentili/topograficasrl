ASSEGNATA THE ROLL

Nuvole di punti / Laser scanner

La homepage è una nuvola di punti 3D navigabile (WebGL) di un cantiere reale. Quattro cluster colorati rappresentano i servizi; al passaggio rivelano dettaglio tecnico come event display. Scroll = profili quota ortogonali.

  • Canvas WebGL full-bleed, 50k punti, rotazione lenta
  • Cluster interattivi → event panel laterale
  • Sezioni ortogonali SVG/Canvas per profili quota
  • Servizi come definition list tecniche
  • Progetti espandibili, testimonianze, team, contatti diretti

CHALLENGER COMPETITIVE

Tensegrità topografica

Metafora strutturale: 5 aste nere (servizi) sospese da cordini arancioni (committenze). La topografia è rete di forze: capisaldi = compressione, linee di vista = tensione. Nodo cliccato = scheda servizio/progetto. Diagramma forze = navigazione.

  • Canvas/WebGL: tensegrità 3D interattiva (aste + cavi)
  • Hover asta → cordini si accendono per committenza
  • Click nodo → event display tecnico (forze, quote, precisione)
  • Scroll = diagramma forze 2D → elenco progetti come nodi secondari
  • Team = "nodi fondanti", payoff in mono engineering
